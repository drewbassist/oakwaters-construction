Lighting That Changes How a Room Feels

Use layers of light to support tasks, atmosphere, and architectural details.

Retrospective topic: March 2024 · Oakwaters Journal

A single bright ceiling fixture rarely provides all the light a room needs.

Use ambient, task and accent lighting

Start with the activities in the room, then assign fixtures to general illumination, focused work and visual interest. Multiple lighting layers are more adaptable than one bright ceiling fixture.

Plan switching and colour consistency

Locate controls where people enter and use the room. Compare lamp colour temperature, dimming compatibility and glare before purchasing fixtures.

Planning prompt: Write down three non-negotiable outcomes for the project, then ask which construction decisions are necessary to achieve each one.
